# ReplayToolbox（配布用）

これは Dalamud プラグイン **ReplayToolbox** の**配布専用**リポジトリです（ビルド済みの配布物だけを置いています）。ソースコードは非公開の別リポジトリで管理しています。

## インストール

Dalamud の設定（`/xlsettings`）→「Experimental」→「Custom Plugin Repositories」に次の URL を追加し、プラグイン一覧から `ReplayToolbox` をインストールしてください。

```text
https://raw.githubusercontent.com/Rin-0617/RinPlugins/main/pluginmaster.json
```

## ReplayToolbox とは

コンテンツリプレイ（A Realm Recorded）のファイルを、プルごとに切り出したり、古いパッチのリプレイを今のバージョンで再生できるように変換したりするプラグインです。
